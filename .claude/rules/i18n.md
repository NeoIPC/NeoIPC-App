## Internationalization

- **The repository owns `i18n/en.pot`; Weblate owns every `i18n/<lang>.po` and is their only writer**, so any repository-side edit of a catalogue, header hygiene included, is a defect: Weblate's next write overwrites it or turns it into a conflict. Make the change in Weblate. The `catalogue-ownership` job in [`.github/workflows/build-and-test.yml`](../../.github/workflows/build-and-test.yml) rejects a pull request in which any `i18n/*.po` carries a commit whose committer is not Weblate, naming each file and how to restore it. `d2-app-scripts i18n extract` writes only the template, and the localized output generated under `src/locales/` is untracked, so nothing needs restoring after a run or regenerating after a Weblate pull request merges. *(repo-specific)*
- **Always** give a source string a Weblate **explanation** wherever it exposes a translator to markup, a placeholder, or an identifier that must survive translation unchanged (an interpolated `{{name}}`, a format token, an embedded tag), saying which part is fixed and which is theirs to translate; explanations live only in Weblate's database, so they cost the catalogue nothing and survive every `msgmerge`. **Remove the exposure where the code allows it, and explain it where removing it would cost more than it saves**: a value the user never sees translated belongs outside the string, while a placeholder the grammar needs mid-sentence earns an explanation. A quality check rejects the mistake after the fact; the explanation prevents it. *(repo-specific)*
- **Always** regenerate `i18n/en.pot` with `yarn build`, **never** with `yarn i18n:extract` alone. The template carries the manifest's strings (the app title, its description, and every command-palette shortcut, as `__MANIFEST_*` entries), which `@dhis2/cli-app-scripts` adds only when the extraction is told it is extracting an app (the `isApp` branch of `cli/src/lib/i18n/extract.js`): its `build` and `start` commands tell it so, its `i18n extract` command does not. A bare `i18n extract` writes a template without them, dropping every translation of the title and the shortcuts on the next Weblate sync, in a diff that reads like an ordinary refresh. *(repo-specific)*
